Throughout this project, I applied Git and GitHub version control concepts to simulate a collaborative software development environment. 
I started by creating a new GitHub repository and cloning it to my local computer. 
I then created separate feature branches to work independently on different sections of a website.

I created a feature/header branch to develop the website header and a feature/footer branch to work on the footer section. 
Using separate branches allowed me to isolate changes, maintain an organized development workflow, and avoid making all modifications directly to the main branch. 
After completing the assigned features, I committed my changes with descriptive commit messages to document the work performed.

During the merging process, I encountered a merge conflict because both branches contained different versions of the index.html file. 
This SBA improved my understanding of Git branching, commits, merging, conflict resolution, and GitHub collaboration.
